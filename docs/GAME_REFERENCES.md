# 成品试玩、玩法参考与前端一致性

## 现在可以玩什么

- 武侠大乱斗：2.5D / 2D 连续开放竹林，镜头跟随角色；敌人从四周围攻。鸠摩智使用环绕飞刀，击杀掉经验，升级选择数量、品质或回复。60秒出现乔峰，范围掌法先显示预警，移出范围可躲避。通关进入下一关。
- 向僵尸开炮：替代旧炮塔案例，使用Three.js与Kenney CC0模型，双路线增援、三种小队、自动射击、空袭/增援/鼓舞和尸潮首领。
- 羊了个羊：保留叠层三消玩法演示，不是官方客户端。

打开 Demo 默认展示成品，点击开始即可玩；「观看制作回放」才播放预录执行记录。回放内容是设计摘要和工具操作示例，不是实时模型执行，也不是模型内部思考。

## 已查阅的参考

1. [canvas-vampire-survivors](https://github.com/ricardo-foundry/canvas-vampire-survivors)：仓库标明 MIT，纯 JavaScript/Canvas，同类生存、武器、经验、Boss玩法参考。本次未复制该仓库代码或素材，因此没有将它列为实际依赖。
2. [鸠摩智转刀介绍](https://m.3839.com/c/156603.htm)：能确认对应作品与作者信息；未找到可核实的原作开源仓库及复用许可。
3. [StarCraft: Ashfall](https://starcraft-shooter-2026.pages.dev/)：参考数字门增援、自动射击和科幻小队的成品方向。已查看的公开页面未提供可核实的源码与素材复用许可。本项目的「向僵尸开炮」是自己的同类玩法实现，不是整站复制或原作换皮，也未导入该站的品牌与素材。

如果以后取得作者允许复用的源码包，可作为模板导入，保留许可证与归属，再接入素材库、预览、下载和发布。网页能游玩并不自动说明其源码或素材采用开源许可。

## Demo 与正式前端

两者现在共用 `CreatorHeader.vue` 和 `creator-theme.css`：Idea2Game品牌栏、紫色强调色、白色圆角面板、左对话右预览与顶部作品操作保持一致。

Demo入口是 `/demo` 或独立 `demo.html`，使用预制游戏与参数编辑，不需要登录。正式入口是 `/app/chat/:id`，保留登录、后端SSE生成、可视化编辑、应用数据、源码下载与部署；顶部显示「AI 实时创作」。正式首页、登录与管理页不等同于Demo创作台，后端服务仍需个人部署和配置。

因此两者采用同一套创作台视觉，但功能数据来源不同；不能把Demo的预制回放当作已经联网生成任意游戏。

## 验证

`npm run test:demo` 覆盖开放世界坐标、四向生成、Boss随世界位置出现、预警躲避、飞刀经验升级、小队强化、分享还原和源码工程导出。`npm run build:demo` 与 `npm run build` 检查Demo及正式前端类型和构建。浏览器检查成品默认可玩、案例切换与实际画面。

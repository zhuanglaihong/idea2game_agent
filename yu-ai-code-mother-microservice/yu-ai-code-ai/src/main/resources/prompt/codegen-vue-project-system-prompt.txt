## 近年流行玩法的实现约束
- 叠层三消：实现遮挡关系、仅顶层可选、有限暂存槽、三张消除、释放下层牌；关卡需有合法解，数量是三的倍数并不保证有解。
- 数字门跑酷/射击：实现左右路线选择、加减乘运算、门仅触发一次、数值驱动兵力或伤害、敌群与Boss；限制实体数量，兵力数字不能直接变成无限个渲染对象，至少保留一条可通关路线。
- 肉鸽/割草/守城：实现波次、经验升级、三选一强化、真实改变属性的技能、冷却与Boss；升级选择期间暂停战斗。
- 合成掉落：实现重力、容器碰撞、同级合并、防止重复合并、顶部超限判定与投放冷却，禁止只画下落动画。
- 科幻小队战斗：实现自动开火、队伍移动、敌人寻路或推进、兵力变化和技能反馈，分离战斗规则与渲染。
- 参考热门游戏时借鉴玩法，名称、角色与素材采用原创主题。用户自由输入的其他游戏类型仍正常生成，不局限于首页入口。

## 游戏生成要求（优先于下方通用页面要求）
- 交付的是完整可玩的游戏，禁止只生成游戏介绍、宣传页、截图或无实际逻辑的按钮。用户只给出一句想法时，自主补齐合理玩法并直接实现；用户没有指定类型时实现简单的收集躲避游戏。
- 先确定玩家目标、操作方式、核心规则、计分或进度、胜负条件。必须实现开始界面、游戏进行、暂停/继续、结束结算和重新开始。说明桌面与手机操作。
- 动作类游戏使用 Canvas 2D 和 requestAnimationFrame，使用 delta time 更新，避免帧率影响速度；益智、卡牌、棋盘类可使用 DOM。必须实现碰撞/规则判定与真实反馈。
- 桌面支持键盘或鼠标，移动端支持触摸按钮、滑动或点击。键盘事件仅在游戏获得焦点或开始后生效，避免方向键导致页面滚动；失去焦点或页面隐藏时暂停并清空按键状态。
- 开始、暂停、重开不能创建重复动画循环或重复事件监听；重开重置分数、计时器、实体与输入状态。Vue 组件卸载时取消动画并清理监听。
- 画布按容器尺寸和 devicePixelRatio 适配，统一逻辑坐标与输入坐标；手机布局不能遮挡操作区。难度循序渐进，初始状态可玩且不存在必败局面。
- 默认用 Canvas、CSS、SVG 或 emoji 绘制游戏素材，禁止依赖随机网络占位图片。外部素材加载失败必须有可用替代。音效使用 Web Audio，首次用户操作后启用，并提供静音按钮。
- 最高分可使用带游戏前缀的 localStorage，读取、解析、写入失败时正常运行。默认单机，不声称支持没有实现的联网、支付或服务器排行榜。
- 用户通过对话修改玩法、难度、关卡、美术或操作时，保留已有游戏的其他行为，输出完整的可运行代码。不得把小游戏改回通用网站。
- 完成前自查：开始能玩、输入有效、计分正确、胜负可达、暂停确实停止、重开状态干净、手机可以操作。代码检查不能替代实际试玩。

## 参考配置

1）vite.config.js 必须配置 base 路径以支持子路径部署、需要支持通过 @ 引入文件、不要配置端口号
```
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  base: './',
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})
```

2）路由配置必须使用 hash 模式，避免服务器端路由配置问题
```
import { createRouter, createWebHashHistory } from 'vue-router'

const router = createRouter({
  history: createWebHashHistory(),
  routes: [
    // 路由配置
  ]
})
```

3）package.json 文件参考：
```
{
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  },
  "dependencies": {
    "vue": "^3.3.4",
    "vue-router": "^4.2.4"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^4.2.3",
    "vite": "^4.4.5"
  }
}
```
